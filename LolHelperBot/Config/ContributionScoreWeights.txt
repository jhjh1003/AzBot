# 비교하는 방식이었는데, 30경기 실데이터 검증 결과 원딜/서폿처럼 특정 지표를 구조적으로

# 그래서 v3부터는 비교 축을 아예 바꿨습니다 — **같은 팀 5명이 아니라 같은 라인의 상대
# (맞라인)와 1:1로 비교**합니다. 정글은 상대 정글러랑만, 서폿은 상대 서폿이랑만 비교하니
# 라인 간 구조적 차이가 원천적으로 사라집니다. (원딜/서폿처럼 듀오 라인인 경우도 "같은
# team_position(같은 라인)의 상대 팀 참가자"로 정의합니다 — 원딜은 상대 원딜과, 서폿은
# 상대 서폿과 비교)
#
# ------------------------------------------------------------
# 지표 목록 (전부 "나 vs 맞라인 상대"의 2자 비율로 계산 — 50이 동률, 100이 완전 압도)
# ------------------------------------------------------------
#   gold_earned          획득 골드 ("성장")
#   creep_score           CS ("골드수급" — gold_earned와 별개로, 순수 파밍 효율만 봄)
#   damage_dealt          챔피언 대상 딜량 ("입힌피해량")
#   damage_taken          받은 피해량
#   cc_time                 적에게 건 크라우드 컨트롤 시간
#   vision_score            시야 점수
#   wards_placed            설치한 와드 수
#   heal_amount             아군에게 건 힐량
#   damage_to_objectives    오브젝트(용/바론/타워 등) 대상 딜량 ("오브젝트 기여도")
#   kda                     KDA = (킬+어시)/max(1,데스)를 맞라인 상대와 비교
#
# 아래 2개는 "맞라인 비교"가 아니라 다른 방식으로 계산되는 특수 지표입니다:
#   kill_participation      (킬+어시)/우리 팀(5명) 총 킬 — 맞라인이 아니라 "우리 팀 전체
#                             KDA에 얼마나 기여했는지"를 보는 지표라서 팀 기준 그대로 사용
#   damage_deficit_offset   **딜량 격차 보정**. 딜량에서 많이 밀렸을수록(예: 탱커형 탑이
#                             딜러형 탑을 상대), 받은피해량·CC가 평균 이상인 만큼 보너스를
#                             줘서 "몸빵/이니시로 기여"한 걸 딜량 부족과 상쇄해줍니다.
#                             (탱커형 vs 딜러형처럼 서로 다른 역할의 챔피언이 같은 라인에서
#                             붙을 수 있다는 걸 감안한 보정)
#   cc_or_heal              CC 기여와 힐 기여 중 **더 큰 쪽**을 자동으로 골라 반영합니다
#                             (서폿이 CC형이든 힐형이든 자기 강점으로 평가받게 하기 위함)
#
